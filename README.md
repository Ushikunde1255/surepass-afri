# surepass-afri

**Pan-African Business Calculation App - No Carryover!**

From MOUAU to Africa. Built to help business students pass, not just study.

### Features
- **62 Topics Covered:** All core Business Calculation / Business Maths topics
- **Snap & Solve:** Take a picture of your assignment, get step-by-step solution (AI Agent)
- **Exam Prediction:** AI predicts likely exam questions from past trends
- **Offline First:** Works for students with low data

### Tech Stack
- Frontend: Flutter / React Native
- AI Agent: Snap-to-Solve (OCR + Math Solver)
- Backend: Python / Firebase

### Vision
To become the #1 academic survival tool for African business students.
